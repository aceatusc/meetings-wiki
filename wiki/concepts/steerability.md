# Steerability

## Definition

Steerability is the user's ability to direct an agent output or process toward the result they want. It differs from feedback because the user is not merely rating an output; they are actively trying to accomplish a task.

## In This Project

Steerability includes:

- requesting edits to a specific step or object
- asking rationale questions at the right point in the process
- selecting functional versus aesthetic focus
- changing a branch or decision point
- propagating a preferred edit across related outputs
- using rubrics to tell the system what matters

## Why It Matters

Users need to fix incorrect, incomplete, or undesirable outputs. A tool that only explains what happened may improve confidence, but the project goal is stronger: make outputs inspectable and actionable.
